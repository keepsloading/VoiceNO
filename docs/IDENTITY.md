# Memact identity

- **Name:** Memact
- **Tagline:** Say it silently.
- **Description:** Silent input for your AI.
- **Name story:** Me + Machine + Action.
- **Brand domain:** memact.com, owned by the founder.
- **First experience:** Record a short silent prompt, review/correct it, and copy it into an AI tool.
- **Python package:** `memact`.
- **Configuration:** `MemactConfig`.
- **CLI:** `python -m memact`.
- **Local project folder:** `memact_new/`.

The previous Memact project explored user context and identity. This project reuses the founder's brand for silent computer input; it does not import that product's architecture or imply that its old services now implement silent speech.

Shared application copy lives in `memact/branding.py`. This migration creates no new logo, accesses no external brand account, and publishes no website. Existing founder-owned logos/assets can be integrated when their files are supplied or identified.
