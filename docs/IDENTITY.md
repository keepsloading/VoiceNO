# VoiceNO identity

- **Name:** VoiceNO
- **Tagline:** You have the right to remain silent.
- **Description:** Silent input for your AI.
- **Repository:** https://github.com/keepsloading/VoiceNO
- **First experience:** Record a short silent prompt, review/correct it, and copy it into an AI tool.
- **Python package:** `voiceno`.
- **Configuration:** `VoiceNoConfig`.
- **CLI:** `python -m voiceno`.
- **Local project folder:** `VoiceNO/`.

Shared application copy lives in `voiceno/branding.py`. Checkpoint provenance, local evaluation fixes, and the Colab workflow are retained through the identity restoration. Current model quality still requires technical investigation.
